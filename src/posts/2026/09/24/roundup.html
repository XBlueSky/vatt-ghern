Radicle 的節點沒在驗身分

#03

Vary 終於進了 Cache Rules

Cloudflare 讓 Cache Rules 支援 HTTP 的 Vary header，每個 header 可以選 normalize、passthrough 或 bypass：Accept、Accept-Language 與 Accept-Encoding 會先轉小寫、按 quality value 排序再進 cache key，Vary: * 則一律繞過快取。Cloudflare 分析了近 5 萬個熱門網站、逾 1.2 億筆回應，將近 3,000 個網站在四個以上的欄位上 vary，有的到 10 個、23 個甚至 47 個，相同的回應被拆散在流量少到熱不起來的快取項目裡。這項功能即日起開放給 Free、Pro、Business 與 Enterprise 方案。

#06

名字以 page- 開頭的資料夾

WordPress 核心的 get_page_template() 有一個不需登入的路徑穿越（CVE-2026-87902，CVSS 9.2），攻擊者能讓頁面樣板解析去 include 主題目錄之外、一個可讀的本機 .php 檔。要升級成 RCE 得同時滿足兩邊條件：啟用中的主題有名字以 page- 開頭的頂層目錄，Twenty Twelve、Twenty Fourteen 與 Neve、Hestia、Sydney 都在此列；伺服器上要有可用的 PHP 檔，例如 register_argc_argv 開著時的 pearcmd.php，官方的 php Docker image 與 PHP 8.5 以前的 cPanel 預設設定都受影響。修正在 WordPress 7.1.2，並一路回補到 4.7 的每個分支。

SAML 的簽章為什麼簽不住

Trail of Bits 的 Matt Schwager 把 SAML 稱為「a fractal of bad design」，主張這套 2002 年由 OASIS 訂出的 XML 協定該退場、換成 OIDC。作者把 XML Signature Wrapping（XSW）稱為 SAML 的致命弱點；文章另點出 enveloped 簽章的問題：Signature 元素被塞進它所簽的 Assertion 裡，一邊改動資料、一邊還要得到位元對位元且 canonical 等價的表示，本來就非常困難。文章也指出 SAML 與傳輸層無關、OIDC 則預設走 HTTP，而現代 99% 的 SAML 實作其實只用到很相近的一小塊子集。

#07

請求成功了，因果鏈卻斷了

一個跑著數千個微服務的大型影音平台在 9 月 23 日上 arXiv 的論文裡攤開自家問題：在自訂佇列、callback 這類不在 instrumentation 路徑上的交接點，payload 繼續往下走、context 卻沒有跟上，請求在既有測試下照樣成功，1,133 個服務裡有 673 個至少帶著一處斷點。Backstitch 是一套專門的 agent 系統，以仍然跑得完的那次執行為對照——先 replay 判斷可疑的呼叫是否與請求相關，再做原始碼分析找到負責的交接點，用有限範圍的改動恢復 context 的傳遞契約，最後用同一次 replay 驗證。修過的 240 個呼叫斷點率從 90.46% 降到 4.69%，112 天內整個 fleet 的斷點率降了一半以上。
