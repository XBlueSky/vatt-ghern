Adaptive execution loop

第三個元件。Runtime 階段如何根據觀察到的實際資料調整 plan。包含一段虛擬的偽碼示意：

while (running) {
  observation = collect_stats(execution_so_far);
  if (deviation_from_estimate(observation) > THRESHOLD) {
    new_plan = replan(observation);
    if (cost(new_plan) < cost(current_plan) * REPLAN_RATIO) {
      switch_to(new_plan);
    }
  }
}

What this enables：三個元件合起來讓系統能在 query 開始執行後仍持續優化計畫，而不是 plan-then-execute 的傳統模型——對 ad-hoc analytical workload 特別有用。
