#04

做了四個月的 LLM router，關掉

Manifest 把一個依複雜度分四級、跨 Anthropic 與 OpenAI 等供應商自動選模型的 router 停掉，理由不是它選錯，是它跟 cache 打架：cache read 比未命中的輸入便宜 75% 到 90%，而一個有效的 router 為了吃到 system prompt 與對話歷史的 cache 必須維持 model stickiness，正好抵消自己存在的理由。更根本的一條是複雜度在 prompt 階段量不出來——同一句任務描述，會因為後續的 tool call 與搜尋而變得「incredibly complex」。這個 router 服務過 7,000 名 cloud 使用者、跑了四個月，九月一日關閉。

rustc 半年快 5.59%，扣掉 rustdoc 只剩 2.90%

Nethercote 的週期性報告：2025 年 12 月到 2026 年 7 月之間，平均 wall-time 進步 5.59%，但把 rustdoc 的成果排除後只剩 2.90%。進步高度集中在周邊工具——rustdoc 整體 wall-time 掉了 28%，Clippy 靠移除 lint 的 no-op 虛擬呼叫在多數情況下快 10% 到 30%。核心路徑的收穫比較零碎：AST 的 expression 節點從 72 bytes 縮到 64 bytes，在吃 AST 的 benchmark 上換到 10% 以上的 wall-time，cache miss 率降了 29%。

#06

Futhark 現在幾乎什麼都能編到 GPU

Futhark 重寫了 flattening，把不規則的巢狀平行——像 map (\n -> i64.sum (iota n)) ns 這種每個元素長度不一樣的情況——先用 fission 拆成簡單運算，再以 segmented array（值向量加旗標向量）改寫成分段形式，作者說現在「modulo compiler bugs and a few unimportant edge cases」可以把任何 Futhark 程式編成平行 GPU 程式碼。代價講得很誠實：多數 benchmark 效能沒變，gmm.fut 的部分 Jacobian 計算有四倍加速，hand.fut 則因為產生的 adjoint 程式碼被過度平行化而慢到兩倍。

#03

把 break 拿掉，case-fold 才跑得動

GitHub 的 code search 要對 180M 個 repo、480TB 原始碼做 Unicode case folding，而把吞吐從 3.1 GiB/s 推到 45 GiB/s 以上的關鍵是刪掉一個最佳化——那個遇到第一個非 ASCII byte 就 break 的提前退出，讓 LLVM 無法向量化整個迴圈。拿掉 break 先到 7.6 GiB/s，改成全無分支（b.wrapping_sub(b'A') < 26 判斷、*b |= u8::from(is_upper) << 5 無條件寫回、迴圈跑完才偵測非 ASCII）才吃滿記憶體頻寬。他們順手把 1,484 組 fold 從約 11.6 KB 壓到 1,776 bytes。

MoQ relay 變成一次 API 呼叫

#08

回源那一段也換成 ML-DSA

Authenticated Origin Pulls 與 Custom Origin Trust Store 現在都吃 ML-DSA 憑證，也就是 FIPS 204 那組後量子簽章，補上 Cloudflare 到 origin 的第二段連線。三組參數 ML-DSA-44、65、87 都支援，官方建議用 44——NIST category 2 的強度，效能代價最小；私鑰要以 FIPS 204 的 seed-only 編碼上傳。Cloudflare 對生態的判斷是「ML-DSA support is increasingly ubiquitous across TLS libraries」，換句話說這件事多半會被例行更新推著走完。

.env 把三件事混成了一件

secretspec 的論點是 .env 把「傳字串給 process」這個交付機制升格成了需求的真相來源，順帶把設定與機密、runtime 值與 build-time 常數也混進同一個檔案，而 KEY=value 這種格式說不出一個值是不是必填、是不是機密、是不是只存在於 production。於是團隊只能靠 .env.local、.env.production 這些檔名編碼環境模型，偏偏各家工具的載入順序互相矛盾——Node 的 dotenv 先到先贏，Docker Compose 後到先贏，Vite 讓既有的 process 變數優先。作者的結論是「A convenience became architecture」，提出的替代是把宣告、儲存與交付拆成三件獨立的事。
