structure

The daily roundup is a curated list of exactly 10 stories from that day, authored by the daily-news skill. Each story gets:

  • Ranking (#1–#10)
  • Title in 繁體中文
  • Lede (2–3 sentences, domain + context)
  • Source link

A stats widget shows today's domain distribution — ensuring diversity across topics like systems, infrastructure, security, data, etc.

required widgets

  • Domain distribution donut chart (SVG) — at least 4 distinct domains represented

visual silhouette

skill input

The daily-news skill produces roundup.html at `src/posts/YYYY/MM/DD/roundup.html` each UTC+8 day. The structure is:

<header class="vg-roundup-hero">
  <h1 class="vg-post-title">{{ title }}</h1>
  <p class="vg-roundup-lede">{{ lede }}</p>
</header>

<section class="vg-roundup-stats" aria-label="today's stats">
  <!-- SVG: domain distribution donut, e.g., 4 colors for 4+ domains -->
</section>

<section class="vg-roundup-list" aria-label="today's stories">
  <!-- 10× <article class="vg-card vg-card-roundup" id="item-NN"> -->
  <!-- each with: .vg-card-roundup-num, .vg-card-title, .vg-card-lede, source link -->
</section>

<section class="vg-roundup-deep" aria-label="today's deep reads">
  <h2>today's deep reads</h2>
  <!-- up to 3× <a class="vg-card-deep"> for deep-story previews -->
</section>

archetype-check rules

  • 10 `<article class="vg-card-roundup">` elements, each with unique `id="item-NN"` (zero-padded)
  • Each item must have `.vg-card-roundup-num`, `.vg-card-title`, `.vg-card-lede` children
  • One `<svg>` for domain distribution (required)
  • `<section class="vg-roundup-deep">` with `<h2>today's deep reads</h2>` (required)
  • 0–3 deep-story preview `<a class="vg-card-deep">` elements
